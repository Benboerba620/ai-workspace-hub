# Workspace Doctor（结构验证）

> 检查对象格式、稳定 ID 和跨文件链接是否完整，不修改研究内容。

## 触发

用户说“检查工作区 / 验证研究结构 / 有没有断链 / workspace doctor”，或完成安装、升级、批量迁移之后。

## 流程

1. 运行 `python system/scripts/workspace_doctor.py`；macOS/Linux 可用 `python3`。
2. 优先解释 `ERROR`：重复 ID、非法状态、错误确定性、断开的研究/Preflight/假设/证据/知识卡/股票池链接，以及研究报告与扫描回执不一致。
3. 再解释 `WARN`：来源元数据不完整、进行中研究尚无 Preflight 等不阻断旧文件兼容的问题。
4. 修复必须遵循文件归属和用户确认边界；验证器本身只读。

## 边界

- `workspace_status.py` 回答“现在做什么”，本工具回答“结构有没有坏”。
- 旧假设的中文状态属于兼容值，不强制批量改写。
- 不因验证失败自动删除、重命名或改变假设结论。
