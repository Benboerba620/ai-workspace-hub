# Hypothesis Review（假设复盘）

> `daily-watch` 日报负责发现新证据，复盘负责改变判断。普通新闻不得自动修改确定性。

## 触发

用户说“复盘假设”，或出现证伪条件、关键催化剂、连续多条同方向证据、财报等重大节点。

## 流程

1. 读取目标 `hypothesis/H*.md`、来源研究报告和复盘期内日报。
2. 只列新增证据，并标为：`强化 / 削弱 / 中性 / 待确认`。
3. 检查数据时间、原始来源以及是否真正对应跟踪指标，避免重复计算同一事件。
4. 给出建议状态：`维持 / 上调 / 下调 / 暂停 / 推翻 / 已兑现`，说明理由。
5. 只有用户确认后，才修改确定性和状态；证据时间线可以按现有自动回写规则追加。
6. 结论稳定后，沉淀或更新 `wiki/explorations/`。

## 边界

- 不因单条普通新闻调整确定性。
- 不把股价涨跌本身等同于基本面证据。
- 不自动交易；触发证伪条件时提醒复盘，而不是替用户下单。
